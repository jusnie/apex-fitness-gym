# Translating Apex Fitness Gym

Apex Fitness Gym stores user-visible strings in `lib/l10n/*.arb`.

## Contribution workflow

1. Start from the current English ARB file.
2. Preserve placeholder names and ICU syntax exactly.
3. Keep fitness terminology concise and suitable for small mobile layouts.
4. Test the affected screens with the target locale before opening a pull request.

Please include the locale code, affected screens, and screenshots where practical. Translation contributions are distributed under the repository's [GPL-3.0 license](LICENSE).
